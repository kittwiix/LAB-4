# Генераторы и встроенные функции Python

Приложение по лабораторной работе № 4 по дисциплине «Теория алгоритмов»,
вариант 10. Уровень сложности — Well-done.

Программа показывает работу функций-генераторов и встроенных функций Python
(`next`, `filter`, `map`, `zip`): случайные ноты, числа, кратные трём, отбор
корректных email-адресов, а также параллельную версию проверки адресов.

## Возможности

- задача 1 — генератор случайных нот из списка `['до', 'ре', 'ми', 'фа', 'соль', 'ля', 'си']`,
  вывод первых 20 значений из 1 000 000;
- задача 2 — бесконечный генератор чисел, кратных 3, начиная с заданного числа;
- задача 3 — фильтрация email-адресов: латинские буквы, цифры и `_`, затем `@` и точка;
- графический интерфейс на PySide6 с четырьмя вкладками `QTabWidget`;
- консольное меню с проверкой ввода;
- параллельная проверка 1 000 000 сгенерированных адресов через `ProcessPoolExecutor`
  и сравнение времени с последовательной версией;
- 56 автотестов pytest.

## Запуск

```bash
python -m venv .venv
```

Активация окружения: `.venv\Scripts\activate` (Windows) или `source .venv/bin/activate`.

```bash
python -m pip install -r requirements.txt
```

Графический интерфейс:

```bash
python main.py
```

Консольное меню:

```bash
python main.py --console
```

Демонстрация без ввода (этот режим запускается в Docker):

```bash
python main.py --demo
```

## Тесты

```bash
python -m pytest -v
```

Проверяются генераторы, формулы, валидация, фильтрация адресов, параллельный
замер и вкладки графического интерфейса. Все 56 тестов проходят.

## Запуск в Docker

```bash
docker build -t generators-lab .
docker run --rm generators-lab
```

В контейнере запускается `python main.py --demo`, потому что для графического
интерфейса нужен экран. Для GUI используйте локальный запуск.

## Краткая справка

- Генератор нот создаётся функцией с `yield`; `take()` забирает первые значения
  через `next()`.
- Первое число, кратное 3, начиная с `a`: `first = a + (-a) % 3`. Следующие
  числа получаются по формуле `a(n) = a(n-1) + 3`.
- Корректный адрес соответствует шаблону
  `[A-Za-z0-9_]+@[A-Za-z0-9_]+\.[A-Za-z0-9_]+`.
- Ускорение параллельной версии: `S = T1 / Tn`, где `T1` — время
  последовательной версии, `Tn` — время версии на `n` процессах.
